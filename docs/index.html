Hardware & Parts List

Everything you need to build this can be sourced for under $15-$25 online.

📦 Required Core Components

  • ESP32-S3 Super Mini Compact dual-core microcontroller with built-in Wi-Fi & USB-C (~$3-$5)
    Required
  • WS2812B RGB NeoPixel Ring (16 LEDs) Bright, individually addressable 5V LED ring light (~$2-$4)
    Required
  • 5V USB-C Power Supply & Data Cable Standard phone charger (1A or higher) and USB-C data cable
    Required
  • Jumper Wires & Soldering Iron Hookup wire or female-female Dupont wires for connections
    Required

✨ Optional Upgrades

  • MAX98357A I2S Class-D DAC Amplifier I2S digital audio DAC & 3.2W amplifier for synthesized arena horns & buzzers (~$2-$3)
    Optional
  • 3W 4Ω/8Ω Mini Speaker Small speaker for enclosure mounting (connects to MAX98357A +/- terminals) (~$1-$2)
    Optional
  • MicroSD SPI Card Module (Optional) Allows loading custom WAV team goal horn sound files (~$1)
    Optional
  • Tactile Momentary Pushbutton Physical celebration test button to trigger lights & horn anytime
    Optional
  • GC9A01 1.28" Round LCD Display Round color screen for live game scores & periods (Phase 3 Roadmap)
    Optional

Wiring & Pin Connections

Straightforward, beginner-friendly wiring for the ESP32-S3 Super Mini.

Component Component Pin ESP32-S3 Pin Description / Wiring Notes
NeoPixel Ring 5V / VCC 5V Connect to ESP32 5V rail (or direct 5V input)
NeoPixel Ring GND GND Common system ground
NeoPixel Ring DI / DIN GPIO 4 Addressable data signal (optional 330Ω resistor in series)
Tactile Button (Optional) Pin A GPIO 9 Configured with internal pull-up (INPUT_PULLUP)
Tactile Button (Optional) Pin B GND Pressing button pulls GPIO 9 to GND to trigger test
MAX98357A I2S DAC (Optional) Vin 5V 5V power rail for 3W Class-D amplifier
MAX98357A I2S DAC (Optional) GND GND Common ground
MAX98357A I2S DAC (Optional) BCLK GPIO 1 Bit Clock (I2S SCK)
MAX98357A I2S DAC (Optional) LRC GPIO 2 Word Select / Left-Right Clock (I2S WS)
MAX98357A I2S DAC (Optional) DIN GPIO 3 Serial Data In (I2S DOUT)
MicroSD Module (Optional SPI) CS / MOSI / CLK / MISO GPIO 10 / 11 / 12 / 13 Standard SPI bus interface (when hardware SD storage expansion is enabled)

Open Source, Community & Transparency

Why this project exists, how it was created, and our commitment to the hockey community.

🏒 100% Free & Open Source (No Subscriptions Ever)

This project was started for personal enjoyment and shared openly so any hockey fan can build their own goal light without paying hundreds of dollars for commercial devices or monthly subscriptions. The source code, 3D printable files, and wiring guides are released completely free under the permissive MIT Open Source license.

🤖 Proudly Vibe Coded

This entire project is proudly vibe coded — engineered collaboratively through modern AI pair-programming and real-world hardware testing. In an era where AI-assisted development is sometimes questioned, we believe in radical transparency: the entire codebase is 100% open on GitHub for security verification, peer review, and pull requests from other makers.

☕ Voluntary Community Donations

There are no required fees, paywalls, or feature locks. If you build this goal light and love having it celebrate your team's goals, voluntary contributions are warmly welcomed to help fund experimental development hardware, test sensors, and hockey coffee!
