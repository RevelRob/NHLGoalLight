ESP32-S3 SUPER MINI

🚨 NHL Goal Light

Install or update firmware directly from your web browser without installing any developer tools or drivers.

  1. Connect your ESP32-S3 Super Mini using a USB-C data cable.
  2. Open this page in Google Chrome or Microsoft Edge.
  3. Click Install Firmware below and select the serial port.
  4. Follow the prompts to connect the device to your Wi-Fi!
⚠️ Web Serial is not supported in this browser. Please use Chrome, Edge, or Brave on a desktop computer. ⚠️ Web Serial requires an HTTPS connection or localhost.
💡 Ensure your USB-C cable supports data transfer (not a power-only charge cable).
