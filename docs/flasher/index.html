ESP32-S3 FIRMWARE (v1.1.0.2)

⚡ Web Browser Flasher

Install or update your NHL Goal Light firmware directly from your web browser with one click. No terminal, Python, or drivers required.

  1. Connect your ESP32-S3 Super Mini (or compatible ESP32-S3) via USB-C.
  2. Ensure you are in Google Chrome or Microsoft Edge.
  3. Click Install Firmware below and choose your USB serial port.
  4. Once flashed, tap Next to enter your home Wi-Fi credentials!
⚠️ Web Serial is not supported in this browser. Please use Chrome, Edge, or Opera on a desktop computer. ⚠️ Web Serial requires an HTTPS connection or localhost.
⚠️ Hardware Compatibility Note:
This build is compiled for the ESP32-S3 (Xtensa LX7 dual-core with native USB CDC, including the compact ESP32-S3 Super Mini). Traditional ESP32 (LX6) and ESP32-C3 (RISC-V) use different CPU architectures and require distinct binary builds.
💡 Ensure your USB-C cable supports data transfer (not a charge-only cable).
If your board does not appear, hold BOOT (0), click RST once, then release BOOT.
